# WorkMind_FE

WorkMind의 프론트엔드 프로젝트입니다.

## 프로젝트 개요

WorkMind는 업무 중 생성되는 문서를 관리하고,
필요한 정보를 검색하고 활용할 수 있도록 만든 업무 지원 서비스입니다.

문서 관리와 AI 분석 결과 확인,
RAG 기반 지식 검색 및 질의응답을 위한 사용자 화면을 제공합니다.

## 주요 화면

- 로그인
- 대시보드
- 문서 관리
- 문서 상세 및 분석 결과
- 지식 검색
- 질의 이력

## 기술 스택

- React
- Vite
- JavaScript
- React Router
- Axios

## AI 활용 개발

프론트엔드는 Codex를 활용하여 구현했으며,
생성된 코드를 직접 검토하고 실행 및 수정한 후 Git으로 관리했습니다.

- UI 및 컴포넌트 구현
- React Router 기반 라우팅 구성
- 백엔드 API 및 JWT 인증 연동
- 코드 검토 및 리팩토링
